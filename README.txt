The design uses a black / warm-gold visual style and is responsive on phone and desktop.

IMPORTANT:
The project thumbnails are placeholders. Add your actual work images later by replacing each thumbnail block in index.html with:
<div class="thumb"><img src="images/project.jpg" alt="Project name"></div>

Free publishing:
1. Create a GitHub account.
2. Create a repository named portfolio.
3. Upload index.html and style.css.
4. Settings > Pages > Deploy from main branch.
5. GitHub will give you a public portfolio URL.

Public-portfolio privacy:
The CV contains personal information that is not needed for a public portfolio. This website intentionally excludes passport number, date of birth, marital status and religion.
